Resumo da Pirâmide de Testes

A estratégia prioriza muitos testes de unidade na base (rápidos e baratos), uma camada intermediária de integração/contrato para validação de comunicação, e menos testes E2E no topo para cobrir fluxos críticos ponta a ponta.

Unidade
Base: maior volume, feedback rápido.
Meio: valida integrações e contratos.
Topo: valida jornada real do usuário.
